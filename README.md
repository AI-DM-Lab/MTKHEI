# MTKHEI

### Mining Top-k High-Efficiency Itemsets

A research project on top-k high-efficiency itemset mining.

> **Repository status: documentation framework.** This repository currently contains the project page only. Algorithm source code, test datasets, experimental results, and executable packages are not included.

[Overview](#overview) · [Paper](#paper) · [Method](#method) · [Usage](#usage) · [Reproducibility](#reproducibility) · [Citation](#citation)

## Overview

MTKHEI studies the discovery of the top-k itemsets ranked by efficiency, where efficiency is evaluated using utility and investment. The user specifies the desired number of itemsets, k, rather than a minimum efficiency threshold.
